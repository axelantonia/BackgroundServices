# GudangKita — Latihan Debugging

Web inventaris sederhana untuk latihan mencari dan memperbaiki bug JavaScript tingkat menengah.

## Menjalankan

Buka `index.html` langsung di browser. Tidak perlu install dependency atau menjalankan server.

## Tantangan

Gejala yang sengaja dibuat terlihat:

- Angka ringkasan tidak cocok dengan isi tabel, dan beberapa angka sulit dibaca.
- Kolom pencarian menimbulkan error saat diketik.
- Tombol **Tambah barang** menimbulkan error saat diklik.
- Hapus barang, reset, penyimpanan, dan ekspor juga perlu diperiksa.

Buka Developer Tools → Console untuk melihat error JavaScript. Coba jelaskan penyebab setiap gejala sebelum memperbaiki.

Tombol **Reset data demo** mengembalikan data awal.
