# Project Instructions

Build an Employee Management CRUD app with employee list and detail views, create/edit/delete, search, validation, delete confirmation, and loading, empty, success, and error states.

## Implementation Rules
- Inspect the existing project and its instructions before changing code.
- Reuse existing components, utilities, and patterns; keep naming and folder structure consistent.
- Keep changes focused on the requested employee workflow and avoid unrelated changes.
- Avoid dependencies unless they solve a clear need that existing tools cannot meet.
- Validate employee input at the appropriate UI and service/API boundaries.
- Handle loading, empty, success, and error states; do not silently swallow failures.
- Keep UI, API/service, business logic, and persistence responsibilities separated.
- Do not introduce unrelated features or modify generated/vendor files unnecessarily.
